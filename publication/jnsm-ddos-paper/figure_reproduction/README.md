# Figure reconstruction from saved outputs

From this directory, run `python3 reproduce_figures.py` after installing
`numpy`, `pandas` and `matplotlib`. The generator produces figures in a local
`figures/` directory, using saved result CSVs under `jnsm_plot_sources/`.
The 2018 three-feature tuple counts are supplied from the author's retained
terminal audit. Output appearance may differ from the final typeset figure PDFs.
No original traffic CSVs are distributed.
